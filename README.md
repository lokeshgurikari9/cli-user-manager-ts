## Project Description

`cli-user-manager-ts` is a simple **Command Line Interface (CLI) application** built using **TypeScript** and **Node.js** that allows users to manage user information directly from the terminal. The application provides a menu-driven interface where users can perform basic user management operations such as adding new users, searching for existing users, deleting users, and displaying all stored users.

This project demonstrates how to build a CLI-based application using TypeScript while applying important software development concepts such as **modular project structure, type safety, and separation of concerns**. The application uses TypeScript interfaces to define the structure of user data and organizes the code into different modules for better readability and maintainability.

The CLI menu interacts with the user through the terminal using the library prompt-sync to collect input and perform operations based on the user's selection. The program runs in a loop until the user chooses to exit, providing an interactive experience within the terminal environment.

This project is designed as a **beginner-friendly TypeScript project** to practice Node.js CLI development and understand how TypeScript improves JavaScript applications through static typing and better code organization.

## Key Features

* Add new users with details such as ID, name, and email
* Search for users by name
* Delete existing users from the system
* Display all users stored in memory
* Interactive CLI menu for easy navigation
* Modular code structure using TypeScript files
* Type-safe user data using TypeScript interfaces
